# Touch Bar Buddies

Clawd (Claude Code's pixel crab) and the Codex pet move into your MacBook Pro's Touch Bar.

They live in the gaps of a faithful copy of your Expanded Control Strip (every button still works), sleep when their app is closed, wake up when you tap them, type on little laptops while Claude or Codex is working, and play together: catch, paper planes, peek-a-boo, and cross-bar visits.

> Early preview. Full install instructions, a demo, and a guide for customizing it with Claude Code or Codex are on the way.

## Quick start (from source)

Needs a MacBook Pro with a Touch Bar, macOS 12+, and the Xcode Command Line Tools (`xcode-select --install`).

```bash
git clone https://github.com/benpham3206/touchbar-buddies.git ~/touchbar-buddies
cd ~/touchbar-buddies && ./install.sh
```

On first launch the app builds its sprites from your own installed Claude and ChatGPT (Codex) apps. No artwork is included in this repo.
