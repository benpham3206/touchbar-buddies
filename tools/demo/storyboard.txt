# The README demo (docs/demo.mp4 + docs/demo.gif), one cue per line. Render it with tools/demo/render.sh.
#
# Times are the renderer's seconds (both buddies start asleep). `do` lines become `--do <command> --at <t>`
# for `TouchBarBuddies --render`; everything else is read by tools/demo/compose.swift:
#   <t> say <codex|clawd> <text> | <seconds>    speech bubble over the buddy's lens
#   <t> prompt <codex|clawd> <text>             typed into that app's window mockup until its buddy starts work
#   <t> caption <text> | <seconds>              caption pill
#   <t> title | <seconds>                       title card on the laptop screen
#   <t> confetti                                confetti over the laptop screen
#   <t> end                                     windows close, end card
#   <t> stop                                    last moment of the video
#   ramp <from> <to> <speed>                    play that stretch faster, with a "▶▶ 4×" badge (the long runs)
#   gif <from> <to>                             the GIF highlight, in seconds of the finished video
# Windows open when a buddy wakes up; they start and finish work when the buddy does (from timeline.json).
